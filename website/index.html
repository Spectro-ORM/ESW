func renderUsers(
    users: [User]
) -> String {
    var _buf = ESWBuffer()
    for user in users {
    _buf.append(#"<li>"#)
    _buf.appendEscaped(user.name)
    _buf.append(#"</li>"#)
    }
    return _buf.finalize()
}

WHAT YOU GET

Templates the
compiler checks.

Compiled at build time.

ESWBuildPlugin turns every .esw and .heex file into a plain Swift function. No runtime parsing; template typos fail the build.

Typed components.

A component tag compiles to a Swift call, so the compiler checks every attribute, slot, and argument type.

Escaped by default.

Output is HTML-escaped unless you opt in. Layouts and partials are ordinary templates you compose as Swift functions.

Live when you need it.

ESWLive keeps state in Swift on the server. A click runs your handler and the browser receives only what changed.

Parameters with types.

The opening block declares typed parameters. Expressions are escaped; the double-equals form inserts trusted HTML, such as another template. This file becomes renderPostsIndex(title: posts: isAdmin:).

Attributes the compiler checks.

Define a component once in Swift. Using it in a template compiles to Card.render(title:footer:content:), with named slots passed as arguments.

Card.swift · profile.heex 
struct Card: ESWComponent {
    static func render(title: String, footer: String = "", content: String = "") -> String {
        #heex("""
        <article class="card">
          <h2>{title}</h2>
          {ESWValue.safe(content)}
          <footer>{ESWValue.safe(footer)}</footer>
        </article>
        """)
    }
}

State stays on the server.

Each click runs handleEvent and re-renders, and the browser receives only the values that changed. Serve it through your own HTTP adapter.

Counter.swift 
import ESWLive

struct Counter: LiveView {
    func mount(_ context: LiveContext) async throws -> Int { 0 }

    func handleEvent(_ event: LiveEvent, state: Int) async throws -> Int {
        guard event.name == "increment" else { throw LiveError.invalidEvent }
        return state + 1
    }

    func render(_ count: Int) -> ESWLiveRender {
        #live("""
        <output id="count">{count}</output>
        <button type="button" esw-click="increment">+1</button>
        """)
    }
}

INSTALL

Add it to
your package.

One plugin does the compiling.

Depend on ESW, and ESWLive for live views. Attach ESWBuildPlugin and put .esw or .heex files in your target; each becomes a render function at build time.

Swift 6.3+ · macOS 14+

Read the guide ↗
Package.swift 
.package(url: "https://github.com/roost-framework/ESW.git", from: "1.5.0")

.target(
    name: "App",
    dependencies: [
        .product(name: "ESW", package: "esw"),
        .product(name: "ESWLive", package: "esw")
    ],
    plugins: [.plugin(name: "ESWBuildPlugin", package: "esw")]
)
